Agent evaluation · flight search

Evaluating a flight‑search agent

I built this to learn how to tell whether an AI agent is actually doing its job, not just producing answers that sound right, using flight planning for two real trips as the test case.

  • The agent searches live Google Flights data for a bachelorette weekend in Mexico City and a honeymoon in Asia, checks each option against the budget, dates and stop rules, and makes a simulated booking.
  • The eval scores every step, not just the final answer, with code-graded checks for accuracy, grounding and safety, because a confident reply can still hide an invented price or a rule-breaking booking.
  • The traces in Langfuse record each run step by step, which is how the problems in the findings were found.
  • The comparison runs the same scenarios on several Claude models to see what each one trades between quality, speed and cost.
